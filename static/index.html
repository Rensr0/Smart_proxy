核心指标

Metrics
综合质量分：剩余寿命 + 延迟(EWMA) + 成功次数 + 新鲜度 + 热池 − 失败降权。
热池：已验证且延迟 ≤ 800ms，优先分配。
平均延迟：池内 EWMA 均值，越低秒用越稳。
健康 IP：探活通过、可直接给业务。
失败计数：失败 +1，成功 −1（不清零）。抓住 flapping，又允许逐步恢复。

隧道与流量

Tunnel
切换：失败换 IP 次数；踢出：软失败累计 ≥3，或拒连/复位等硬失败立即移出。
自适应超时：按 EWMA + 剩余 TTL 动态计算建连超时（约 0.35～1.5s）。
建连对冲：主连接挂起约 120ms 后并行备用出口，先通者胜；只对冲建连，不对冲业务流量。救场＝备用出口赢了；空跑＝主连接已通、对冲白开。
当前/峰值带宽：隧道转发速率，Redis 持久化。

质量校验

Verify
每 1s 扫描 未验证 新 IP，多线程探活百度首页。
软失败累计达标才踢出并补货；已测过不重复测。
「本轮通过率」只统计新 IP；「累计」为进程内汇总（跨重启恢复）。
